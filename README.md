# Smart-lamp
Лампа, которая будет регулироваться с помощью приложения.
Яркость, контраст, время, по которому она будет работать - всё это делается через приложение, которое будет в дальнейшем создано. К примеру можно поставить, чтобы лампа включалась в 18:00, а выключалась в 00:00, либо просто выключить по одной кнопке в приложении.
